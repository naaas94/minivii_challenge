## §2. Shared Contracts

### Types / Interfaces (T6 owns these)

```python
# nlp/eval/harness.py
from dataclasses import dataclass

@dataclass
class TestCase:
    question: str
    expected_class: str
    expected_clauses: list[str]    # substrings that must appear in generated SQL (case-insensitive)
    forbidden_clauses: list[str]   # substrings that must NOT appear in generated SQL
    known_answer: str | None = None

@dataclass
class JudgeScore:
    factual_accuracy: int          # 1–5
    interpretation_fidelity: int   # 1–5
    issues: str | None = None

@dataclass
class EvalReport:
    results: list[dict]
```

### PipelineResult fields consumed by T6

T6 calls `pipeline.run(question)` directly and reads:
```
pipeline_result.sql                        str
pipeline_result.execution.data             list[dict] | None
pipeline_result.execution.success          bool
pipeline_result.execution.steps_taken      int
pipeline_result.execution.failure_reason   str | None
pipeline_result.narrative                  str | None
pipeline_result.query_class                str
pipeline_result.total_latency_ms           int
```

### Error Envelope
T6 calls `Pipeline.run()` directly (not via HTTP). No HTTP error handling needed in the harness.

### Naming
- Module path: `nlp.eval.harness`
- Eval entrypoint: `python -m nlp.eval.harness` (or `python nlp/eval/harness.py`)
- Report output: `logs/eval_{timestamp}.json`
- `skip_judge` parameter: `True` for Phase 2 (Together.ai), `False` for Phase 3 (Ollama)

### Tests
The 12 test cases ARE the test suite. The harness must not crash on individual case failures — catch per-case, record failure, continue.

**Inputs:** T4 — Pipeline importable and all pipeline components complete.

**Outputs:**
1. `nlp/eval/harness.py` with `check_sql_structure`, `judge_synthesis`, `run_eval`, and the 12 `TestCase` instances
2. `run_eval` prints per-case progress to stdout
3. `run_eval` writes `logs/eval_{timestamp}.json` with all results
4. `EvalReport` returned from `run_eval`

**Kill criteria:**
- HALT if any of the 12 test cases references a non-POS domain question (no CRM, SaaS, enterprise deals, or quarterly segments)
- HALT if `check_sql_structure` uses exact string match instead of substring containment (`lower in sql_lower`)
- HALT if `judge_synthesis` calls the LLM when `narrative` is `None` (must guard: if narrative is None, return None for judge_score)
- HALT if `run_eval` raises an unhandled exception on a single failing case — must catch per-case with `try/except` and record `failure_reason`
- HALT if test case #1 (`expected_clauses`) does not include both `week_day` and `friday` (case-insensitive substring check)
- HALT if test case #4 (`expected_clauses`) does not include `2024-10` (October revenue query)
- HALT if test case #6 `expected_clauses` does not include `strftime` OR `forbidden_clauses` does not include `substr(` — this is the structural check for spec correction C1 (ISO date normalization; the old broken formula must be caught)
- HALT if test case #10 `expected_clauses` does not include `sum(quantity)` AND `forbidden_clauses` does not include `sum(total)` — verifies disambiguation fired and chose quantity over revenue ranking
- HALT if test case #11 `expected_clauses` does not include both `where` and `date` — verifies the "recent" disambiguation fired and produced a date filter (not a full-table scan)
- HALT if `JudgeScore` construction from LLM JSON response does not have a fallback for parse failure

**Risks & mitigations:**
- The judge prompt expects a JSON-only response. Add `parse_json` with a fallback: if JSON parsing fails, return `JudgeScore(factual_accuracy=0, interpretation_fidelity=0, issues="parse_error")`.
- Print per-case progress: `print(f"[{i+1}/12] {case.question[:50]}... {'PASS' if sql_pass else 'FAIL'}")`.
- The full eval (12 cases × synthesis + judge) takes 90–120 minutes on GPU. This is expected and documented.

### `check_sql_structure` (spec §7)

```python
def check_sql_structure(generated_sql: str, case: TestCase) -> dict:
    sql_lower = generated_sql.lower()
    passes = [c.lower() in sql_lower for c in case.expected_clauses]
    fails  = [c.lower() in sql_lower for c in case.forbidden_clauses]
    return {
        "pass": all(passes) and not any(fails),
        "expected_present": list(zip(case.expected_clauses, passes)),
        "forbidden_present": list(zip(case.forbidden_clauses, fails)),
    }
```

### `judge_synthesis` (spec §7) — with parse fallback

```python
def judge_synthesis(self, question, result_data, narrative) -> JudgeScore | None:
    if narrative is None:
        return None
    sample = result_data[:10]  # match synthesis truncation
    summary = {"total_rows": len(result_data), "columns": list(result_data[0].keys()) if result_data else []}
    prompt = f"""...evaluate narrative...
Respond with JSON only:
{{"factual_accuracy": <int>, "interpretation_fidelity": <int>, "issues": "<str or null>"}}"""
    response = self.llm_client.generate(prompt, model=self.synthesis_model)
    try:
        return JudgeScore(**parse_json(response))
    except Exception:
        return JudgeScore(factual_accuracy=0, interpretation_fidelity=0, issues="parse_error")
```

### `run_eval` structure

```python
def run_eval(self, test_cases: list[TestCase], skip_judge: bool = False) -> EvalReport:
    results = []
    for i, case in enumerate(test_cases):
        try:
            pipeline_result = self.pipeline.run(case.question)
            sql_score = self.check_sql_structure(pipeline_result.sql, case)
            judge_score = None
            if not skip_judge and pipeline_result.narrative:
                judge_score = self.judge_synthesis(
                    case.question, pipeline_result.execution.data, pipeline_result.narrative
                )
            result_entry = {
                "question": case.question,
                "class": pipeline_result.query_class,
                "sql_pass": sql_score["pass"],
                "sql_detail": sql_score,
                "judge": dataclasses.asdict(judge_score) if judge_score else None,
                "latency_ms": pipeline_result.total_latency_ms,
                "steps_taken": pipeline_result.execution.steps_taken,
                "failure_reason": pipeline_result.execution.failure_reason,
            }
        except Exception as e:
            result_entry = {"question": case.question, "error": str(e), "sql_pass": False}
        results.append(result_entry)
        print(f"[{i+1}/12] {'PASS' if result_entry.get('sql_pass') else 'FAIL'}: {case.question[:60]}")
    return EvalReport(results=results)
```
