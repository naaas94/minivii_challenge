## §1. Task Statement

Build Mini Nivii — a domain-scoped NL-to-SQL BI agent — from scratch as a Docker Compose application with four containers (`db`, `nlp`, `ui`, `ollama`). This subtask creates all scaffolding: directory tree, Dockerfiles, `docker-compose.yml`, `ollama` entrypoint, `requirements.txt` stubs, and the YAML semantic layer descriptor. No Python business logic is written here.

**Non-goals:**
- Python business logic in any service
- LLM-based AmbiguityDetector (production enhancement only)
- Multi-table schema or database joins
- CI pipeline or automated regression testing
- External network calls in the submitted system

**Kill criteria:**
- HALT if any port in docker-compose deviates from db:8001/nlp:8002/ui:3000/ollama:11434
- HALT if `ollama` entrypoint uses `sleep N` instead of polling loop (`until curl -sf http://localhost:11434/api/tags`)
- HALT if `nlp depends_on ollama` condition is not `service_healthy`
- HALT if `models_ready` sentinel file path in healthcheck deviates from `/tmp/models_ready`
- HALT if `domain.yaml` content deviates from spec §5.2 (including `date_range`, `kpis`, `disambiguation_rules` sections)
- HALT if `data.csv` is included in the Docker build context (must be volume-mounted, not COPYed)
- **HALT if `docker-compose.yml` includes a `deploy.resources.reservations.devices` block for the `ollama` service** — this causes unconditional failure on machines without NVIDIA Container Toolkit. The `ollama/ollama` image detects GPU at runtime; no explicit reservation is needed.

**Risks & mitigations:**
- **GPU `deploy.resources` block: omit entirely from `docker-compose.yml`.** The `driver: nvidia` reservation causes `docker compose up` to fail with "could not select device driver nvidia" on any machine without NVIDIA Container Toolkit installed — regardless of whether GPU is needed at runtime. The `ollama/ollama` image detects and uses CUDA automatically at runtime when the NVIDIA runtime is present; no explicit `deploy.resources` declaration is needed. Document in the README and in a compose comment that GPU is used automatically if the NVIDIA Docker runtime is available, with no configuration required. Do not include any `deploy.resources.reservations.devices` block.
- `entrypoint.sh` must be `chmod +x` or the Docker `mode: 0755` config entry must be present.

## Key Implementation Notes

### `docker-compose.yml` structure (from spec §6)

```yaml
version: "3.9"

services:
  db:
    build: ./db
    ports: ["8001:8001"]
    volumes: ["./data.csv:/app/data.csv:ro"]
    networks: [nivii-net]
    healthcheck:
      test: ["CMD", "curl", "-sf", "http://localhost:8001/health"]
      interval: 10s
      retries: 5

  ollama:
    image: ollama/ollama
    volumes: ["ollama_cache:/root/.ollama"]
    entrypoint: ["/bin/sh", "/entrypoint.sh"]
    configs:
      - source: ollama_entrypoint
        target: /entrypoint.sh
        mode: 0755
    networks: [nivii-net]
    healthcheck:
      test: ["CMD", "test", "-f", "/tmp/models_ready"]
      interval: 30s
      timeout: 10s
      retries: 60
      start_period: 60s
    # GPU note: ollama/ollama detects and uses NVIDIA CUDA automatically at runtime
    # when the NVIDIA Container Runtime is installed. No deploy.resources block needed.
    # CPU-only machines run normally — generation is slower (see README).

  nlp:
    build: ./nlp
    ports: ["8002:8002"]
    networks: [nivii-net]
    depends_on:
      db:
        condition: service_healthy
      ollama:
        condition: service_healthy
    environment:
      - DB_URL=http://db:8001
      - OLLAMA_URL=http://ollama:11434
      - SQL_MODEL=qwen2.5-coder:14b
      - SYNTHESIS_MODEL=qwen3:32b

  ui:
    build: ./ui
    ports: ["3000:3000"]
    networks: [nivii-net]
    depends_on:
      nlp:
        condition: service_started

configs:
  ollama_entrypoint:
    file: ./ollama/entrypoint.sh

volumes:
  ollama_cache:

networks:
  nivii-net:
    driver: bridge
```

### `ollama/entrypoint.sh` (from spec §6)

```bash
#!/bin/sh
ollama serve &

echo "Waiting for Ollama API..."
until curl -sf http://localhost:11434/api/tags > /dev/null 2>&1; do
    sleep 2
done
echo "Ollama API ready."

echo "Pulling SQL model..."
ollama pull qwen2.5-coder:14b

echo "Pulling synthesis model..."
ollama pull qwen3:32b

touch /tmp/models_ready
echo "Models ready. Ollama serving."
wait
```
