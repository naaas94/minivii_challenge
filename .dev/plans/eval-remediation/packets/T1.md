## §1 Task statement

Implement the five-priority eval remediation strategy for the minivii NLP pipeline. The pipeline currently produces a false-positive pass rate (83% structural) because the eval harness ignores `execution.success` when computing `case_pass`. This subtask (Wave 0) adds an execution tier gate to the harness and redefines `case_pass` with a breaking-but-honest formula. No pipeline code is touched.

**Non-goals (this subtask):**
- Pipeline code changes (disambiguation, SQL generation, classifier, synthesizer).
- `result_assertions` / semantic assertion vocabulary on `TestCase` — deferred.
- SQL post-processor hooks — out of scope for this plan.
- Known-answer fuzzy matching — deferred.
- Architecture doc updates.
