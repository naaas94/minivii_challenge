## §1 Task statement

Implement the five-priority eval remediation strategy for the minivii NLP pipeline. Case 12 ("most returns by product") produces correct execution but missing `WHERE total < 0` because the SQL model ignores domain semantics despite full schema injection. This subtask (Wave 2) adds a deterministic constraint injection in `sql_generator` and a targeted few-shot example so the model receives explicit guidance for returns queries.

**Non-goals (this subtask):**
- SQL post-processor / `lint_returns_filter` — explicitly out of scope (Flag 8 resolution: P1-A+B and P2-A+B are sufficient).
- Result-level validation in observer (Option D) — deferred.
- `result_assertions` on `TestCase` — deferred (Flag 5 resolution).
- Classifier, disambiguation, or synthesizer changes — owned by T2/T4/T5.
- Architecture doc updates.

**ID:** T3

**Inputs:** T2 complete (plan gates T3 start on T2 complete so full eval is valid after; no direct code dependency).

**Outputs:**

- New or extended test in `test_sql_generator.py`

**Kill criteria:**
